# Cálculo Factura (Android)

App para dividir la factura de luz (Air-e) + agua (AAA):
- Linda 30 %  - Rafael 30 %  - Ricardo = valor restante (40 %)
- Pestaña **Configuración** para poner foto de perfil a cada persona.

## Compilar el APK con GitHub (sin instalar nada)
1. Crea un repositorio nuevo en GitHub (vacío).
2. Sube TODO el contenido de esta carpeta (incluida la carpeta oculta `.github`).
3. Ve a la pestaña **Actions** -> "Build APK" (corre solo con el push, o pulsa "Run workflow").
4. Al terminar (~3-5 min) abre la ejecución y descarga el artefacto **CalculoFactura-apk** (contiene `CalculoFactura.apk`).
5. Pasa el APK al celular e instálalo (permite "instalar apps desconocidas").
